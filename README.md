# 取手・競輪シミュレーター Phase 3

Astroの静的ページ＋Canvas。局面・ライン関係・位置・車間・進路と局所乱数から展開を生成します。着順や仕掛け担当を事前生成するアニメーションではありません。実在選手の能力差はありません。

## 起動・検証・公開

Node.js 22以上。`npm ci` → `npm run dev`。
`npm test`で検証。`BASE_PATH=/-/ npm run build`でGitHub Pages用のdistを生成。
mainへのpushで既存のGitHub Actionsがビルド・Pagesデプロイします。
公開URL: https://yuhevita-wq.github.io/-/

## 維持する基礎

9車＋誘導員、真上固定視点、4倍速、START / PAUSE / RESET。RESETは同一配置・新しいseed。
2025m（5周＋25m）、先頭の残り800mで誘導員が内側へ連続退避して停止。競走・着順には復帰しません。
先頭の残り400mで序盤のレーン補助表示を解除。s・dは常に連続座標で、レーン番号による横移動命令はありません。
物理は1/240秒刻み。前後は速度・進行量の安全制約で重なりを防ぎ、反発・前車の押し出しはありません。
横接触は強度とseed付き局所乱数により横ズレ・減速・進路変化を発生。落車なし。
ゴールはステップ内の通過時刻を補間し、その順で確定。9車ゴール後に停止。同じseed・設定・操作条件は再現可能です。

## 内部設計

- `track.mjs`: 既存の取手形状・幅・座標変換。変更なし。
- `race.mjs`: ライン定義と検証、局面境界、分断・再結合の閾値。
- `engine.mjs`: 同一時点のスナップショット、観測・関係状態、誘導員、既存の物理積分と安全制約、横接触、ゴール。
- `controller.mjs`: 役割別判断、走行空間の評価、非同期の行動更新、追走・連続横位置の目標。物理と交換可能な意思決定層。
- `view.mjs`: 描画・操作。折りたたみの「ライン・局面デバッグ」で所属、役割、基本/現在追走、行動、分断を表示。

## ラインデータ

初期値はA=1–5–7、B=3–8–4、C=2–6–9。これは初期所属だけで、先頭順位や勝者ではありません。

```js
import { Simulation } from './src/sim/engine.mjs';
import { lineController } from './src/sim/controller.mjs';
const sim = new Simulation(42, lineController, {
  lines: [
    { id: 'A', members: [1, 5, 7] },
    { id: 'B', members: [3, 8, 4] },
    { id: 'C', members: [2, 6, 9] },
  ],
});
```

1〜9を各1回、ラインIDは重複不可。入力をコピーするので外部変更は状態に影響しません。
各車は`lineId / role / baseFollowId / currentFollowId`を保持。役割は先頭・番手・3番手。
座標・速度は全車独立で、ラインを棒のように拘束しません。

## 局面

境界は`race.mjs`の`PHASES`で管理し、`Simulation`の`options.phases`でも差し替え可能です。残り距離は先頭基準。

| 局面 | 残り距離 | 判断の重点 |
| --- | --- | --- |
| A | 1100m超 | ライン形成、位置維持 |
| B | 1100〜800m | 他ラインとの位置取り |
| C | 800〜600m | 誘導退避、主導権争い |
| D | 600〜400m | 仕掛け |
| E | 400〜200m | 最終周の追走・位置変化 |
| F | 200m以下 | ライン追走の重みを段階的に緩める |

局面更新は共通の観測情報だけです。各車は反応時間と0.8〜1.9秒の判断間隔を持ち、局面変更時にタイマーや行動を一斉リセットしません。Fの自由化も各車自身の残り距離を自分の判断時刻に評価します。

## 先頭の判断

他ライン先頭の前後・横位置と速度、進路上の空き、自ライン後続の遅れ、誘導員までの距離、局面を認識。
連続横位置の候補を前方の空き・横移動量・内側への距離で評価し、物理的な合流制限も確認します。

- HOLD: 位置維持。必要に応じて前方ラインの先頭に距離を合わせる。
- ADVANCE: 他ラインとの距離を詰め、空いた進路へ上がる。
- DROP: 後続が伸びたB/C局面、または並走・混雑で進路を確保できないとき、一旦速度を抑える。
- ATTACK: 後半で進路が空き、前方ラインとの距離・相対速度・残り距離から仕掛ける理由がある場合。

前方のライン先頭のみが誘導員を追走対象にします。全車には誘導中の追い越し防止上限が残りますが、これは所属・追走対象の指定とは別です。

## 番手・3番手と分断

番手は自ライン先頭、3番手は番手を優先。近い別ライン車を発見しても直ちに対象を変更しません。
所属上の追走相手とは別に、進路上の障害車を観測して安全減速します。
車間・相対速度による加減速と各車の反応差で、ラインは伸縮します。

以下が1.5秒続くと分断：車間18m超、横差2.5m超、別ライン車の割り込み、基本追走相手が後方にある状態。
分断後、割り込みや遠距離などで追走が難しい場合に限り、進路上の車を一時追走します。基本追走相手は保持し、その横位置へ復帰を試みます。
基本相手が前方・車間10m未満・横差1.2m未満・割り込みなしを1秒維持すると再結合。
最終200mは追走関係の重みを連続的に下げ、空いた進路への移動とゴールへ向かう速度を優先。安全制約は緩めません。

## 形状の根拠と限界

ユーザー承認済みの「公式図の輪郭＋公式寸法による近似」。測量図の再現ではありません。

- [取手公式バンクガイド](https://www.toride-keirin.com/guide): 周長400m、見なし直線54.827m。
- [公式SVG案内図](https://www.toride-keirin.com/assets/default/img/content/guide/bank.svg): 内側輪郭の直線284.8単位・半径約95.75単位を400mに相似縮小。図上の決勝線位置も反映。一般的な楕円への置換はしない。
- 2026年公式GIIIリーフレットの寸法: ホーム10m、バック10m、センター7.5m。区間間の幅は滑らかに補間。
- 公式図は案内図であり、緩和曲線や各地点の実際の幅変化は分からない。輪郭比率と公表幅を優先するため、案内図の外縁そのものとは一致しない。
- 発走点25m手前は2025m運用の設定。公式掲載のスタート写真のみから現地の正確な座標までは復元していない。
- カント公表値（センター31°30′25″、直線2°51′44″）は参考情報。現段階は平面の玩具物理であり、傾斜・タイヤ・空力の実車物理モデルではない。
- 内側基準の400mモデル。外側走行の距離増加は曲率に応じて計算。

現実の競走結果を予測する精度は評価していません。
