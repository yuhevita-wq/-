# 取手競輪シミュレーター：レース現象

現在の400mバンク、拡張された走路と表示倍率、将棋駒、車番色、紫＋黄色0の誘導員、走行方向、4倍速、START/PAUSE/RESETを維持したレースモデルです。
実在選手の能力・得点・脚質・オッズは使用しません。全員の初期脚残量と最大能力は同じです。

## 実行

`npm ci` → `npm run dev`。`npm test`で単体・物理・再現性検証。
`node scripts/check-races.mjs 10`でseed 1〜10の全レースを再計算し、JSON行形式で現象と検証結果を出力します。
`BASE_PATH=/-/ npm run build`でGitHub Pages用distを生成します。
mainへのpushで既存のActionsがbuild・Pagesデプロイします。
公開URL: https://yuhevita-wq.github.io/-/

## 結果を先に作らない

意思決定は同時点の位置・速度・前後左右の空き・所属・追走対象・残り距離・脚残量から行います。
乱数は判断間隔、反応、仕掛け・牽制・切替を選ぶ際の揺らぎと既存の横接触だけに使います。
ランダムな横座標・巡航速度・勝者・最終隊列は生成しません。
ゴール通過時刻を既存の物理ステップ内で補間し、通過順で着順を確定します。

## 序盤からゴールまで

誘導中は現在の密集した一本棒を維持。先頭の残り800mで誘導員が退避し、その後は座標補正でラインを作らず、先頭の位置取りと後続の合流・追走で形成します。
先頭は後続が離れていれば初期のペースを抑え、後続は他車を避けながら所属車へ合流します。

既定ラインはA=1–5–7、B=3–8–4、C=2–6–9。`Simulation(seed, controller, {lines})`で変更可能です。
所属と基本追走相手は保持し、切替先は別状態として保存します。切替後に必ず元へ戻す処理はありません。

| 局面 | 先頭の残り距離 |
| --- | ---: |
| 誘導追走 | 800m超 |
| 誘導退避 | 800〜740m |
| ライン形成 | 740〜660m |
| 位置取り | 660〜600m |
| 上昇・抑え | 600〜540m |
| 主導権争い | 540〜480m |
| 仕掛け | 480〜400m |

局面は観測用の共通境界です。実際の状態選択は所属・位置・自車の残り距離・脚・進路を併用し、0.55〜1.45秒の独立した判断時計で更新します。誘導中から時計を動かし、退避時の全車一斉判断を避けます。

## 実装した判断

- **MOVE_UP / CONTROL**：後方から外の進路へ上昇。先頭へ到達した場合にペースを落とし抑える。
- **RESIST / YIELD**：外の上昇へ内から踏む、または消耗を避けて下げる。長時間の並走では判断をやり直す。
- **KAMASHI / MAKURI**：速度差・位置・脚・空きから開始。外へ出る→加速→接近→並走→通過を観測。カマシは通常上昇より加速上限が大きい。
- **不発**：進捗停止・長時間の仕掛け・脚の低下で追走へ戻る。成功判定には実際の前方ライン通過が必要で、成功抽選は行わない。
- **番手**：車間維持、先頭の急加速への追走、外の仕掛けへの小幅な牽制、失速した先頭を交わす判断。
- **3番手**：追走、離れた車間の回復、合流車の回避、分断後の他ラインへの切替。
- **BLOCK**：外の接近車に応じて番手が最大約0.6m外へ目標を動かす。横速度の上限と合流制限を通し、ワープ・強制押し出しはしない。
- **TRAPPED**：前が遅く、横も塞がっていれば脚が残っていても減速する。
- **SPRINT**：終盤に前車の速度・脚残量・空きを確認して所属追走を緩める。先頭・番手・3番手で移行理由が異なる。

前後の安全制約と横接触は既存処理を維持します。脚があっても安全制約は無視しません。
車間は速度、曲率、追走・牽制・追い上げの状態で変わります。固定座標によるライン拘束はありません。
分断は車間18m超・横差2.5m超・割り込み・基本相手が後方の状態が1.5秒継続した場合。接続可能な状態が1秒続くと所属上の分断表示を解除します。切替先はこれとは独立して維持できます。

## 脚の消耗

全車100から開始。高速度の継続、急加速、コーナー外側、横移動、接触で消耗します。
前車の近くを追走すれば負荷が軽くなり、低負荷の追走時にはわずかな回復が可能です。
脚残量で最高速度・加速上限を連続的に下げます。外へ出ただけで瞬間的なペナルティを与えず、実走行時間に応じて負荷を積算します。
定数は全車共通で、車番・ライン・選手タイプ別の能力差はありません。

## 観測・検証

折りたたみデバッグで所属、役割、現在追走、状態、分断、狙う横位置、脚残量、判断理由を確認できます。
`events`と`attempts`は実際に起きた状態変更・仕掛けを記録する観測ログで、結果の生成には使いません。

古いテストには、最新mainの走路拡張や誘導中一本棒と矛盾する期待値が残っていたため、現状仕様に合わせて更新しています。
旧来のライン所属・追走・分断/再結合・非同期判断の検証は維持し、古い4状態の判断テストは新戦術のシナリオ検証へ置換しました。

### seed 1〜10の実行結果

全10レースで9車完走、着順は10通り。仕掛け時計の同時一斉切替なし、誘導退避後の後方反発なし、サンプルした物理占有域の重なりなし。

| 観測項目 | 発生レース数 / 10 |
| --- | ---: |
| 2本以上のライン接続 | 9 |
| ラインの伸縮 | 10 |
| ライン分断 | 10 |
| 捲り成功 | 4 |
| 捲り不発 | 10 |
| 残り200mの先頭が先頭役のまま勝利 | 5 |
| 最終200mから番手が自ライン先頭を交わす | 4 |
| 切替 | 10 |
| 内詰まり | 8 |
| 残り200mから着順の入替 | 9 |

同一レースで成功と不発の両方が起こる場合があります。成功は狙った前方ラインの実通過、不発は進捗停止・消耗・ゴールまで未通過で判定し、勝利とは別です。2本以上の接続は各ライン3車の前後順・18m未満の間隔・横差1.3m未満を観測した場合です。seed 4はこの条件を満たす2本同時接続がなく、合流が安定しないケースとして残っています。

## 残る限界

これは実車の空力・出力を較正したモデルではなく、競輪現象を成立させる簡易ルールです。現象の発生率が実競輪と一致するとは確認していません。
誘導中は現行の表示間隔補正を維持し、完全な自律車間モデルには変更していません。
退避後の所属車への合流にはばらつきがあり、三本すべてがきれいに揃う保証はありません。
表示駒は物理寸法より大きいため、退避後の密集時は見た目上の重なりが残る場合があります。
牽制は連続横移動と空間制約だけの近似です。失格・審議・斜行判定・落車は実装していません。

## 形状の根拠と限界

ユーザー承認済みの「公式図の輪郭＋公式寸法による近似」。測量図の再現ではありません。

- [取手公式バンクガイド](https://www.toride-keirin.com/guide): 周長400m、見なし直線54.827m。
- [公式SVG案内図](https://www.toride-keirin.com/assets/default/img/content/guide/bank.svg): 内側輪郭の直線284.8単位・半径約95.75単位を400mに相似縮小。図上の決勝線位置も反映。一般的な楕円への置換はしない。
- 2026年公式GIIIリーフレットの寸法: ホーム10m、バック10m、センター7.5m。区間間の幅は滑らかに補間。
- 公式図は案内図であり、緩和曲線や各地点の実際の幅変化は分からない。輪郭比率と公表幅を優先するため、案内図の外縁そのものとは一致しない。
- 発走点25m手前は2025m運用の設定。公式掲載のスタート写真のみから現地の正確な座標までは復元していない。
- カント公表値（センター31°30′25″、直線2°51′44″）は参考情報。現段階は平面の玩具物理であり、傾斜・タイヤ・空力の実車物理モデルではない。
- 内側基準の400mモデル。外側走行の距離増加は曲率に応じて計算。

現実の競走結果を予測する精度は評価していません。
