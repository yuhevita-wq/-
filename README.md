# 取手・競輪シミュレーター Phase 1

Astroの静的ページ＋Canvas。着順の事前生成や結果抽選は行わず、各車の位置・速度・局所的な乱数・接触からゴール順が決まります。

## 起動

Node.js 22以上。`npm ci` → `npm run dev`。
`npm test`で物理検証、`npm run build`で静的出力（dist）。
GitHub Pagesの /-/ 配下に置く場合は `BASE_PATH=/-/ npm run build`。

## 初号機の仕様

- 9車、実時間4倍速、START / PAUSE / RESET。RESETは同一配置・新しい乱数シード。
- 試走距離2025m（5周＋25m）、発走点は決勝線の25m手前。
- 先頭が最終周へ入ると全車のレーン目標を解除。
- レーン制では9本の離散目標。隣接レーンへの移動は連続運動で行い、接触判定を省略しない。
- 最終周は走路幅内の連続した横方向運動。
- 1/240秒の固定物理刻み。長さ1.9m、幅0.65mの楕円状当たり判定。表示は別寸法。
- 前後・横接触、減速、横方向への反動。横接触の強さ・減速量に局所乱数。落車なし。
- フィニッシュ時刻はステップ内の通過を補間。同じシードは再現可能。UIでは毎回新規シード。
- ゴール済み車も走行を続け、全9車のゴール後に停止。

## 構造

`src/sim/track.mjs`: 形状・幅・座標変換。
`engine.mjs`: 位置、速度、接触、境界、周回、ゴール判定。
`controller.mjs`: 玩具用の加減速・隣接レーン選択・横移動。将来の意思決定との交換点。
`view.mjs`: 描画と操作。計算は表示フレームレートから独立。

選手能力、ライン戦術AI、オッズ、車券、予想、機械学習、落車、他場対応は未実装。

## 形状の根拠と限界

ユーザー承認済みの「公式図の輪郭＋公式寸法による近似」。測量図の再現ではありません。

- [取手公式バンクガイド](https://www.toride-keirin.com/guide): 周長400m、見なし直線54.827m。
- [公式SVG案内図](https://www.toride-keirin.com/assets/default/img/content/guide/bank.svg): 内側輪郭の直線284.8単位・半径約95.75単位を400mに相似縮小。図上の決勝線位置も反映。一般的な楕円への置換はしない。
- 2026年公式GIIIリーフレットの寸法: ホーム10m、バック10m、センター7.5m。区間間の幅は滑らかに補間。
- 公式図は案内図であり、緩和曲線や各地点の実際の幅変化は分からない。輪郭比率と公表幅を優先するため、案内図の外縁そのものとは一致しない。
- 発走点25m手前は2025m運用の設定。公式掲載のスタート写真のみから現地の正確な座標までは復元していない。
- カント公表値（センター31°30′25″、直線2°51′44″）は参考情報。現段階は平面の玩具物理であり、傾斜・タイヤ・空力の実車物理モデルではない。
- 内側基準の400mモデル。外側走行の距離増加は曲率に応じて計算。

現実の競走結果を予測する精度は評価していません。
